# FurniEra – Furniture E-Commerce Website

FurniEra is a furniture e-commerce web application developed as part of a university Web Programming project. The platform provides a modern, responsive interface for exploring furniture products, browsing collections, and interacting with shopping features.

The project is being developed using a **Single Page Application (SPA)** architecture, with frontend functionality implemented in the first milestone and backend integration planned for subsequent milestones.

## Project Overview

FurniEra aims to create a user-friendly online furniture shopping experience with an attractive interface, organized product categories, and smooth navigation.

The website uses dynamic content loading to navigate between pages without requiring a complete browser refresh.

## Features

### Milestone 1 – Frontend Development

- Responsive website design using HTML5, CSS3, and Bootstrap.
- Single Page Application architecture using SPApp and jQuery.
- Dynamic navigation without full-page reloads.
- Home page featuring furniture collections and promotions.
- Shop page displaying furniture products.
- About Us page with information about the platform.
- Blog section featuring furniture-related content.
- Contact page with a form and frontend validation.
- Shopping cart interface with quantity controls and price calculations.
- Checkout page interface.
- Interactive product filtering and testimonial slider.
- Consistent navigation bar and footer across the website.
